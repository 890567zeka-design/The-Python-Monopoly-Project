# 🎲 The Python Monopoly Project

**Классическая настольная игра "Монополия" на Python** с красивым консольным интерфейсом.

Поддержка покупки улиц, строительства домов, карт «Шанс» и «Общественная казна», тюрьмы и полноценной игровой механики.

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)

## ✨ Возможности

- Полноценная игровая доска (40 клеток)
- Покупка собственности и оплата ренты
- Строительство домов и отелей
- Карты «Шанс» и «Общественная казна»
- Механика тюрьмы
- Поддержка 2–6 игроков
- Красивый цветной вывод в консоль

## 🛠 Технологии

- Python 3.10+
- Объектно-ориентированное программирование (ООП)
- `dataclasses`, `colorama`
