# 🎲 Упрощённая Монополия (консольная версия)

Проект для курса «Языки программирования Python».  
Реализация базовой механики игры «Монополия» с объектно-ориентированным подходом и консольным интерфейсом.

## 🎯 Особенности

- 💰 **Валюта** — рубли (₽)
- 🇷🇺 **Русскоязычный интерфейс** — все названия клеток и сообщения на русском
- 🎲 **Визуализация кубиков** — ASCII-графика при броске
- 🃏 **30 уникальных карт** — 15 карт «Шанс» и 15 карт «Общественная казна» с различными эффектами
- 🏠 **30 клеток на доске** — улицы, налоги, шанс, казна, тюрьма
- 👥 **2-4 игрока** — динамическая настройка количества участников
- 💸 **Покупка и аренда** — полная экономическая модель
- 🔒 **Обработка ошибок** — защита от некорректного ввода

## 🚀 Запуск

### Требования
- Python 3.6 или выше
- Консоль с поддержкой UTF-8 и моноширинного шрифта

### Установка и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/ltokdsi/The-Python-Monopoly-Project.git

# Перейдите в папку проекта
cd The-Python-Monopoly-Project

# Запустите игру
python main.py
